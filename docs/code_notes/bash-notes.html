Command Line Notes

Useful command line utilities and programs with Bash
Author

Henry Watkins

Command line programs and Bash scripts can be remarkably useful and flexible for a whole range of tasks. It is often easier to use the capabilities of mature command line programs and simple bash scripts than write custom python scripts.

The Unix philosophy

  1. Write programs that do one thing and do it well.
  2. Write programs to work together.
  3. Write programs to handle text streams, because that is a universal interface.

Basic commands

ls - list contents of directory

pwd - present working directory

cd - change directory

cp - copy a file (-r recursive for whole directories)

mv - move file, also used to rename

rename - batch rename files, using the sed style patterns

rm - delete a file (-r recursive for directories)

touch - create an empty file

mkdir - create a directory

less - print out the scrolling contents of a file

cat - print out the whole contents of a file, for multiple files, it concatenates them together

head -n X - display the first X lines of a file.

tail - same for the end lines

sudo - run with root privileges

date - prints out date and time

time - time the execution time of a program

timeout - run program with pre-defined time limit after which it is cancelled

echo - display a line of text, or the value of an environment variable

chmod - change permissions of a file or program, +x useful for making scripts executable.

reboot - reboot the computer, after an interval

shutdown - shutdown the computer, after an interval

ps ,top and htop - list processes

tree - display the constituent files and folders of this directory in a tree structure.

tee display output and also write to file

find - locate files and folders

Command line extras

| - pipeline key, feed output from one command to another, e.g. ls | grep "filename"

; - successive commands, in a simple line join multiple commands together e.g. cmd1 ; cmd2; cmd3

> - send output to a file, e.g. ls > contents.txt, doubling it >> means appending it to the end of a file

< - send file to stdin e.g. grep "hello" < hello_world.txt

* - wildcard, matches any pattern. Useful for searching for filetypes, removing multiple files etc.

-h - a very common option for almost all commands, dsiplays help info and the manual for a command e.g. grep --help

= - define variables e.g. VAR1=/path/to/file

$ - access predefined variables e.g. $VAR1

You can also use brackets with $ to define more complicated, calculated variables e.g. $(wc -l file.txt)

Useful programs

grep - regex search utility, search for a regex pattern in plain text

nano - simple terminal-based text editor

xargs - enables more complex chain commands on the command line

shred - completely destroy file

wget - download a file from the internet, supply with the path

gdb - simple debugger

gprof - simple profiler

micro - a terminal-based text editor, more features than nano

vim - the venerable terminal editor

uniq - find the unique rows in some output. filters out matching lines from input.

sort - sort the output

join - concatenate two files together

curl - curl is useful for transferring data to and from servers using URLs. Its is particularly useful for interacting with REST APIs and SQL queries.

bash - use to run command-lines .sh scripts. particularly useful if you need more than a single line for you operation. Can be added as as shebang #!/usr/bin/env bash

wc - counter, counts the number of things, line lines, words, bytes, chars.

seq - print out a sequence of numbers

nl - given a sequence of lines, add line numbers

comm - compare two files line by line (or stdin). It is useful for finding the intersection and difference between two files with the options -12, -23 respectively.

jq - simple interface to json files, use to quickly explore and process json files. e.g. cat test.json | jq '.["key"]'

yq - similar to jq, but for yaml, toml files

diff - compare two files, printing out lines where they differ, useful for debugging and error analysis.

man - display the manual for a program

cut - print/select selected lines from input

history - display last few commands you used

grex - create regex patterns from a set of examples you wish to capture

tar - used to create tarball files. This is an archive file that sticks a group of files together and compresses them for long term storage and transfer. e.g. tar -czvf output_tarball.tar.gz diretory_to_compress

tqdm - the python tqdm library for progress bars but in terminal

aspell - command line spell checker

proselint - command line linter for grose/grammar

column - simple tabular processing

xclip - post things to clipboard to copy/paste easily e.g. cat file | xclip then paste to stdout with xclip -o

which - locate executable

du - disk usage

ln - create symbolic/hard links

source - execute commands from a file in the shell

export - set environment variables

Not so useful programs

factor - find the prime factors of some integers

shuf - random permutation of input lines

du - disk usage, print out the files, directories and their memory usage

fold - wrap input lines of a file

split - split up a file into separate files of some length

fmt - simple text formatter, squishes everything into lines of some specified length

crontab - schedule commands to run regularly at a specified time

basename - returns the top-level name of a path with all the upper directories removed, e.g. /home/user/dir/file -> file

dirname - returns the rest of the paths

Parallel jobs

you can run multiprocessing across several processes using the parallel.

Background jobs

One can use & to send the command or job to run in the background. Then view the background running jobs with jobs -l. To pull it to the foreground again use fg <job id>. e.g.

job-command-1 & 
jobs -l
fg <job id>

Also use wait to ensure all background processes to finish before continuing. This is particularly useful if there are outputs of one stage that are required by the next stage.

Note jobs/fg/& is limited to one session, and processes started with & will be terminated if the shell session ends. To run jobs in the background independently of the shell session, use screen, which acts as a terminal multiplexer to run long processes irrespective of the shell session.

pipelines

A key concept of terminal processing and bash scripting in general is pipelines. Here then pipe operator | is used to pass the result of one text-based command to another, enabling complex one-line programs.

awk

Useful for command-line exploration and basic processing of datasets. Use is to quickly view tables of data and basic processing in combination with grep , cat and | > operators.

Basic usage is of the form

awk [options] 'selection-criteria {action}' file

Some useful examples and options

awk -F ',' 'NR<10 {print $2}' data.csv

Print out the second column of the first 10 rows of a comma-separated-value dataset.

awk is especially powerful when used in combination with grep sort uniq . For example we can find the unique values in a column using

awk -F ',' '{print $2}' | sort | uniq

Awk is particularly well suited to simple operations that one could do using pandas, but without needing to write a script or open jupyter

sed

sed is a stream editor, it can be used to modify piped in streams or files of text. You can use it for selecting, printing (p), substituting (s), adding lines (a, i), deleting lines (d) and modifying files. It relies on pattern matches with regex, much like grep.

Follows the general pattern

sed -n 'selection action' file

select lines 1-4 and print to terminal

sed -n '1,4p' file

substitution

echo helloworld | sed 's/world/city'
sed '7,9 s/day/week/gip' file

for lines 7 to 9, replace ‘day’ with ‘week’, in case-insensitive manner (i), globally (g) so we perform the match-replace more than once, and print (p) the output.

cut entire lines that match the pattern

sed '/pattern/c replacement_text' file

append after lines that match pattern

sed '/pattern/a text_to_append' file

insert before lines that match

sed '/pattern/i text_to_insert' file

delete lines

sed '3d' file

use the -n option to quietly perform operation, only print out the lines selected, particularly useful for long files.

Save you changes by outputting to a new file with > or by performing operations in place with -i option.

A super useful application is in converting CSVs to TSVs for use with awk

sed -E 's/("([^"]*)")?,/\2\t/g' file

You can create sed scripts to perform more complicated and saved tasks. script.sed e.g.

4i\ 
s/,/\t\t/
s/,/ /

And run with sed -i -f script.sed filename

ssh

ssh - open secure connection between hosts on a network

sshfs - mount a remote filesystem securely

scp - secure copy between hosts on a network

datamash

datamash is a basic data processing command-line tool which performs basic numeric, textual and statistical operations on input textual data files.

Examples:

calculate the sum and mean of values 1 to 10:

seq 10 | datamash sum 1 mean 1
55 5.5

group text file by one column and calculate mean and sample standard deviation on another, with automatic sorting and header line processing:

datamash --sort --headers groupby 2 mean 3 sstdev 3 < scores_h.txt
GroupBy(Major)  mean(Score) sstdev(Score)
Arts            68.94       10.42

csvkit

csvkit is a suite of command-line tools for converting to and working with CSV. The key components are csvlook, csvcut, csvstat, csvgrep, csvsort, in2csv, csvstack, sql2csv, csvsql, csvformat.

pspp

pspp is a statistical command line tool based on the spss software. It is used for performing statistical analyses on tabular data.

llm

The llm library is a good CLI for tasks querying large lanuage models. It is a fantastic addition to the aformentioned command line utilities to solve complex problems strait from the command line.

llm library

gnuplot

gnuplot is a command line plotting utility. It can be used to create simple plots and graphs from data files, or from the output of other command line programs. It is particularly useful for quick visualisation of data without needing to write a script or open a jupyter notebook. It is thus the ideal companion to the command line utilities and bash scripts. The quality of the plots is very good; comparable to matplotlib and seaborn. In fact it was the standard for academic plotting before matplotlib became popular. The usage is similar to python in that you can run it via an interpreter or a script.

gnuplot plotscript.gnu

Bash scripts

Bash scripts can be remarkable capable. Combining variables, simple loops and pipeing alongside mature programs like grep and awk can create sophisticated scripts.

For example, if I wants a short program to extract the phone numbers for all names starting with G, from a table of names and numbers, I can use:

#!/bin/bash

# Check for input argument (file name)
if [ "$#" -ne 1 ]; then
    echo "Usage: $0 <filename>"
    exit 1
fi

# Assign the file name to a variable
input_file="$1"

# Check if the file exists
if [ ! -f "$input_file" ]; then
    echo "File '$input_file' not found!"
    exit 1
fi

# Extract lines where the name starts with G, then extract phone numbers using awk
grep "^G" "$input_file" | awk '{print $2}'

Data processing with bash

With all these tools, it becomes clear that bash scripts can be created to build sophisticaed data processing pipelines. Together with standard command-line tools like grep, awk, sed, jq and gnuplot, you can create powerful scripts to process and analyze data without needing to write custom Python or R scripts. We could for example create a bash script to pull data from a database with sqlite3 (see also notes on SQL), process it with awk and sed, and then visualize it with gnuplot.

#!/bin/bash
# Example bash script to process data from a SQLite database and visualize it
# Query data from SQLite database
sqlite3 my_database.db "SELECT date, value FROM measurements;" > data.csv

# Process the CSV: extract columns, clean up, and convert to TSV
awk -F',' '{print $1 "\t" $2}' data.csv | sed 's/"//g' > data.tsv
# Run gnuplot to create the plot
gnuplot plotscript.gnu

echo "Plot saved as plot.png"

Combined with the command line interfaces to some other popular software such as the statistical software R, or the large language model library, you can create sophisticated data processing pipelines that are easy to run and modify.
